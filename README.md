# React Wordle Clone

A Wordle-inspired word puzzle application developed
using React, JavaScript, HTML, and CSS.

## Features

- Six attempts to guess the hidden word.
- Five letters per guess.
- Physical keyboard support.
- Interactive virtual keyboard.
- Backspace and Enter functionality.
- Green, yellow, and gray feedback.
- Win and loss conditions.
- Restart game functionality.

## Installation

Install dependencies:

npm install

Start the application:

npm run dev

Build for production:

npm run build

## Technologies

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
